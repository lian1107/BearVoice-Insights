# BearVoice 受控 AI 原声洞察工作流

## 服务的重复决策

本工作流服务客服数据运营、产品经理、品质人员和模型审核员，用于把每批脱敏客户原声转换为可追溯的多信号、候选主题和待审核产品机会。它不代替产品立项、质量定性、召回、商业收益或发布签字。

## 运行与费用控制

外部模型分析通过 Temporal 后台任务执行。HTTP 上传只完成数据落库、预算预留和任务入队；Worker 以固定批次和并发上限执行。临时传输错误或严格 JSON 契约错误使用指数退避重试。每条通过校验的模型结果先写入逐条检查点，进程失败后只补跑缺失记录；最终候选信号仍整批原子发布，不把半成品混入业务结果。

预算采用两道硬门禁：单任务上限，以及按日期和模型提供商累计的单日上限。预留调用数包含有界重试额度并受单任务上限截断；Worker 在每次外部调用前用并发安全计数器检查硬上限，不能用自动重试绕过预留额度。金额根据管理员配置的保守单次预留值计算，用于阻止失控调用；它不是财务结算数据，财务核对仍以供应商账单为准。

## 标准输出

每个 AI 信号必须包含类型、生命周期阶段、对象、问题、场景、潜在需求、连续原文证据、未校准置信度、风险级别、待验证根因假设和缺失信息。输出不能包含契约外字段，证据必须是脱敏输入中的连续原文。

## 拒绝与升级

- 模型未授权、端点未批准、密钥缺失或非 HTTPS：拒绝外发，升级给系统管理员。
- 输入未通过隐私门禁：阻断模型外发，升级给数据治理负责人。
- 输出出现疑似隐私：确定性脱敏并增加人工复核提示；纯脱敏占位符不作为洞察展示。
- 响应截断、空响应或 JSON 不合规：按有界次数重试；耗尽后记录为未解析并转人工，不伪造信号。
- 证据未逐字对齐：回退为脱敏原声片段，并明确提示人工缩短证据。
- 涉及人身安全、召回、品质根因或立项：AI 只准备证据和缺口，升级给具名品质/产品负责人。
- 缺销量、订单或退换修分母：可生成待验证假设，不输出收益或因果结论。

## 上线前五类测试

| 类型 | 用例 | 当前结果 |
|---|---|---|
| 正常 | 一条原声产生多个合规信号 | 通过；严格持久化 |
| 边界 | 无产品信号时返回空列表 | 通过；不伪造问题 |
| 缺输入 | 原声或 `run_id` 为空 | 通过；模型调用前拒绝 |
| 冲突 | 证据不在原文或声称已校准 | 通过；证据有界回退，虚假已校准声明拒绝 |
| 拒绝/高风险 | 敏感响应、截断、预算耗尽或某条持续不合规 | 通过；脱敏、硬停止或显式转人工，不伪造 Signal |
